# Evidence chain

The public evidence path is:

```text
task and scenario state
  -> prompt/request payload
  -> raw hosted-model response
  -> parsed action vector
  -> deterministic replay from represented and authoritative state
  -> feasibility, violation, distance, and cost scores
  -> within-block branch comparison and matched deterministic baselines
  -> claim registry and manuscript table
  -> SHA-256 release manifest
```

## Where each layer is stored

| Layer | Public package location |
|---|---|
| Frozen task, carrier, prompt/request, raw response, parsed action | `frozen_inputs/project/**/records/` |
| Scenario definitions and protocol/config snapshots | `frozen_inputs/project/scenarios/`, `frozen_inputs/project/experiments_v2/`, and tier-specific protocol directories |
| Deterministic replay and saved score material | record objects plus `frozen_inputs/project/segan_revision_major_v2/reviews/offline_completion_20260829/input_snapshots/` |
| Archived parser source | `protocol_code/experiments_v2/` and `protocol_code/e2b_parser_v2.py` |
| Analysis and independent replay implementation | `scripts/` |
| Branch-, block-, model-, dose-, event-, gate-, and baseline-level results | regenerated under `reproduced_outputs/`; frozen references under `reference_outputs/` |
| Claim-to-row selectors | `reference_outputs/audit/claim_to_evidence_registry.json` |
| Released record hashes | `manifests/PUBLIC_RECORD_MANIFEST.jsonl` |
| Final package manifest | generated by the release workflow under `RELEASE_METADATA/` |

Every released record is a saved historical object. The offline runner does not call a hosted model and does not substitute regenerated text for a raw response.

## VCR and H5/E5 closure

`python3.12 RUN_ALL_OFFLINE.py` finishes by running `scripts/verify_vcr_h5e5.py`.
The verifier checks the following as one fail-closed chain:

- **VCR:** 825 released record/block files are verified by public hashes; 3,538 actual historical provider calls are represented, with two protocol-recorded E2 structured skips. The exact archived parsers independently reproduce all 3,526 parsed objects associated with successful saved responses; 14 failed or skipped calls are explicitly not applicable.
- **H5:** 2,940 claim-bearing evidence rows retain task, prompt/request, raw response or explicit failure/skip, parsed action, saved replay/score, within-block comparison identity, timestamps, and hashes.
- **E5:** 1,800 dual-replay comparisons reproduce with zero numeric or flag disagreement, and the independent checker reproduces 4,620 physics verdicts with zero discrepancy.

The generated reports are `reproduced_outputs/parser/PARSER_REPLAY_VERIFICATION.json` and `reproduced_outputs/vcr_h5e5/VCR_H5E5_VERIFICATION.json`. The frozen expected contract and reference receipts are included in `VCR_H5E5_EXPECTED.json`, `reference_outputs/parser/`, and `reference_outputs/vcr_h5e5/`.
