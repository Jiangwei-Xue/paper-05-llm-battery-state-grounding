# Result files

`reference_outputs/` contains the frozen expected outputs used for equivalence
checks. A successful one-command run writes a separate sibling output tree with
the same logical areas:

- `primary/`: historical F1/F0 branch, block, gate, and baseline metrics;
- `qwen37/`: separate Qwen3.7-Plus metrics and gate sidecars;
- `physics/`: independent replay and violation checks;
- `audit/`: denominator, objective, timeout, and provenance audits;
- `sensitivities/`: optimization, robustness, and activity analyses;
- `semantics/`: explicit represented-state versus authoritative-state results;
- `tables/`: regenerated LaTeX tables;
- `parser/`: raw-response parser-replay receipt;
- `vcr_h5e5/`: unified evidence-chain receipt;
- `acceptance/`: adversarial release acceptance report.

The output tree is not prepacked because it is deterministic and regenerated by
`RUN_ALL_OFFLINE.py`. `results_manifest.json` and
`docs/paper_results_map.md` map these results to all nine paper tables.
